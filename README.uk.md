<h3 align="center">Аналіз Wireshark — там, де вже лежить захоплення.</h3>

<p align="center">
  <code>pcaptui</code> — це термінальний інтерфейс до <code>tshark</code>: список пакетів,
  дерево протоколів і шістнадцяткова панель, через SSH, на машині без дисплея — не
  копіюючи 2&nbsp;ГБ захоплення назад до себе.
</p>

<p align="center">
  <img src=".github/assets/demo.svg" alt="Відкрити захоплення, спитати що в ньому, спитати що з ним не так, і опинитися на проблемних пакетах" width="100%">
</p>

<p align="center">
  <sub><b>y</b> що в цьому файлі · <b>e</b> що з ним не так · <b>enter</b> перейти до тих пакетів</sub>
</p>

```bash
go install github.com/m1rwana12/pcaptui/cmd/pcaptui@latest

pcaptui -r traffic.pcap          # файл
pcaptui -i eth0 'port 443'       # інтерфейс
tcpdump -w - port 53 | pcaptui -r -
```

Потрібен [`tshark`](https://www.wireshark.org) у `PATH` — підійде будь-який за останнє
десятиліття. Якщо його немає, `pcaptui` скаже про це прямо, а не впаде пізніше так,
ніби зіпсоване саме захоплення.

---

## Що ви отримуєте

**Захоплення, яким можна рухатись.** Прокручуваний список пакетів, дерево протоколів,
яке розгортається, і шістнадцяткова панель, що підсвічує байти вибраного поля.
`tcpdump` друкує рядки — тут можна дивитись.

**Фільтри Wireshark, які перевіряються під час набору.** Той самий синтаксис, і поле
фільтра червоніє ще до натискання enter. Фільтр із командного рядка теж
перевіряється: описка зупиняє програму поясненням від самого `tshark`, а не відкриває
порожнє вікно.

**Усі дисектори Wireshark — і кожен новий.** `pcaptui` не має власних знань про
протоколи й жодних думок про них. Він питає `tshark`. Коли Wireshark вивчає новий
протокол, його вивчає й ця програма — без жодного релізу тут.

**Відповіді, а не лише пакети.** Expert Information каже, що дисектори вважають
неправильним у захопленні; Protocol Hierarchy каже, що в ньому є. Обидва — таблиці,
з якими можна працювати: enter на рядку звужує список пакетів до тих, про які цей
рядок.

**Програма каже, коли показує не все.** Завузька колонка завершує значення на `…`, а
не показує тихо коротшу адресу; у заголовку видно, скільки пакетів і чи фільтр —
причина короткого списку; статистика, яка нічого не знайшла, каже це словами, а не
відкриває порожнє вікно.

## Аналіз

Вісім виглядів, по клавіші на кожен — та сама літера стоїть біля них у меню Analysis.

| Клавіша | | |
|---|---|---|
| `o` | **Overview** | усі три питання одразу, на одному екрані |
| `e` | Expert Information | що дисектори вважають неправильним |
| `y` | Protocol Hierarchy | що в цьому захопленні, деревом |
| `t` | Endpoints | хто є на дроті, найактивніші перші |
| `w` | HTTP | чим закінчились HTTP-відповіді, за статусом |
| `v` | Conversations | хто з ким говорив, у пакетах і байтах |
| `s` | Reassemble stream | зібрати потік, до якого належить пакет |
| `p` | Capture file properties | розмір, тривалість, інкапсуляція, хеші |

<p align="center">

І Expert Information, і Protocol Hierarchy поважають накладений фільтр, тож можна
питати їх про підмножину; обидва називають фільтр угорі результату.

## Розшифрування TLS

Якщо у вас є сеансові ключі, ви бачите відкритий текст:

```bash
export SSLKEYLOGFILE=~/keys.log     # далі запустіть браузер або curl
pcaptui --tls-keylog ~/keys.log -r traffic.pcap
```

`pcaptui` перевіряє журнал ключів до запуску й відмовляється стартувати, якщо файл
відсутній або нечитабельний. `tshark` приймає неіснуючий шлях до ключів, стартує
нормально, виходить із кодом нуль і нічого не розшифровує — тобто описка інакше
виглядала б точнісінько як трафік, ключів до якого у вас ніколи не було.

## Пересування

| | |
|---|---|
| `/` | фільтр відображення |
| `tab` | перемикати панелі |
| <code>&#124;</code> `\` | розкладка панелей, збільшення панелі |
| `ctrl-f` | пошук — за фільтром, шістнадцятковими байтами, текстом або регуляркою |
| `ma` `'a` | позначити пакет, повернутися до нього |
| `c` | режим копіювання — пакети, поля або весь потік |
| `?` | усе решта |

Клавіші vim працюють скрізь. Миша — у більшості терміналів теж.

## Чи це для вас?

**Так, якщо** захоплення лежить на сервері, або завелике, щоб його переносити, або ви
вже знаєте фільтри Wireshark і хочете їх там, де трафік.

**Радше ні, якщо** ви за робочим столом зі встановленим Wireshark, а файл перед вами.
Графічний інтерфейс Wireshark кращий за будь-який термінал. Ця програма існує для
випадків, коли його немає.
